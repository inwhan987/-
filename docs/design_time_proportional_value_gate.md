# 대장주 선별 — 시간비례 거래대금 게이트 설계 논의

작성: 2026-08-11
목적: 다른 AI/동료 검토용. 현재 파이 실운영 상태와 제안안, 열린 의사결정 항목 정리.

## 1. 배경 — 대장주 봇 개요

- 한국 주식(코스피/코스닥) 자동매매 시스템의 "대장주(leader)" 엔진
- **선별 → 진입 → 청산** 파이프라인
  - **선별(pick)**: 09:30~13:00 사이에 후보 유니버스에서 매매 대상을 슬롯별로 골라 스위치
    - `LEADER_SWITCH_UNTIL = "13:00"` (이 시각 이후엔 pick 안 함, 보유만 유지)
  - **진입**: 3분봉 스윙저점 후 회복확인(LEADER_RECLAIM) 시 매수
  - **청산**: +4% 익절 또는 규칙 기반
- 유니버스 소스: 매경(시총) ∩ 다움(거래대금 랭킹 각 시장 300종목) → KIS(J, KRX) 로 실시간 확인

## 2. 현재 게이트 스택 (선별 단계)

후보 종목은 아래 게이트를 **모두** 통과해야 슬롯 후보로 들어감:

1. **시총 하한** (`market_cap`)
2. **거래대금 하한** (`min_value_by_market`) ← **본 문서의 논의 대상**
3. **등락률 컷** (`LEADER_SEL_RISE_MIN` 등)
4. **평소대비 거래대금 배수** (`vol_mult`, 회전율)
5. **회전율 하한** (`base + slope × frac`)

## 3. 현재 거래대금 게이트 구현 (leader_finder.py)

### 3.1 세션 진행률 (`_session_fraction`)

```python
_SESSION_MIN = 390  # 09:00 ~ 15:30
def _session_fraction(now):
    elapsed = (now - start_0900).total_seconds() / 60.0
    frac = elapsed / _SESSION_MIN
    return min(max(frac, 0.02), 1.0)
```

- 09:00→0, 11:00→0.308, 13:00→0.615, 15:30→1.0
- 하드 플로어 0.02 (개장 직후 폭주 방지)

### 3.2 시장강도 배수 (`_compute_intraday_flow_multiplier`)

```python
baseline = avg_full_5day × frac       # 지금 시각까지 "정상이면" 나왔을 거래대금
raw      = today_val / baseline
mult     = clip(raw, low=0.5, high=1.5)
```

- 시장별(kospi/kosdaq) 각각 계산
- 반환값 예: `{"kospi": 1.12, "kosdaq": 0.87}`
- 캐시된 5일평균은 **하루완결 close 값** → frac은 15:30 세션 기준이 자연스러움

### 3.3 최종 컷 (게이트 적용)

```python
base = args.min_value * 1e8           # LEADER_SEL_MIN_VALUE_EOK = 400  → 400억
mults, _ = _compute_intraday_flow_multiplier(...)
min_value_by_market = {
    "KOSPI":  base * mults["kospi"],
    "KOSDAQ": base * mults["kosdaq"],
}
```

- **주의**: `base` 는 시간비례가 **없음**. 시간과 무관하게 400억이 flat.
- 시장강도 mult(0.5~1.5)만 붙어서 200억~600억 사이에서 흔들림.

### 3.4 현재 문제

- 09:30 컷 = 400×mult. 개장 30분 만에 400억 나온 종목이 매우 적어 pick pool 이 5~10 종목 수준. **아침 컷이 사실상 병목**.
- 사용자 관찰: "아침에 400억 고정이니까 거의 안 나오더라"

## 4. 제안 — 시간비례 도입

### 4.1 두 세션 정의 분리

- **session_frac** (기존): 09:00~15:30 (390분 기준). **배수/시장강도/회전율 게이트 유지**.
  - 이 게이트들은 하루완결 값(avg5, 하루 총 회전율 튜닝)과 비교되므로 15:30 기준이 의미상 맞음.
- **pick_frac** (신규): 09:00~13:00 (240분 기준). **거래대금 절대 하한에만 사용**.
  - Pick 은 13시에 끝나므로 13:00 = 100% 로 정규화하면 게이트가 pick 창 안에서만 스케일링됨.
  - `pick_frac(t) = min(max((t - 09:00) / 240min, 0.02), 1.0)`

### 4.2 앵커 개념

- 사용자가 "이 시각에 이 하한이 적당하다" 는 기준점을 정의:
  - `anchor_value` = 앵커 시각에서의 목표 하한값 (억)
  - `anchor_hhmm` = 앵커 시각 (예: "11:00")
- 임의 시각 `t` 의 하한:

```
하한(t) = anchor_value × (pick_frac(t) / pick_frac(anchor_hhmm)) × market_mult
```

- 두 축이 동시에 적용됨:
  - **시간비례** (`pick_frac / pick_frac_anchor`)
  - **시장강도** (`market_mult`, 기존 그대로)

### 4.3 현재 검토중인 값

- `anchor_value = 500억`
- `anchor_hhmm = "11:00"` → `pick_frac(11:00) = 0.5`

시뮬 (mult 0.5~1.5 범위):

| 시각  | pick_frac | 저조 0.5× | 보통 1.0× | 활황 1.5× |
|-------|-----------|-----------|-----------|-----------|
| 09:30 | 0.125     | 63        | 125       | 188       |
| 10:00 | 0.250     | 125       | 250       | 375       |
| 10:30 | 0.375     | 188       | 375       | 563       |
| **11:00** | 0.500 | 250       | **500** ⚓ | 750       |
| 12:00 | 0.750     | 375       | 750       | 1125      |
| 12:30 | 0.875     | 438       | 875       | 1313      |
| 13:00 | 1.000     | 500       | 1000      | 1500      |

- **11시 앵커 (현재 유력)** — 중간. 오전은 완만, 오후엔 대형주로 압축
- **10:30 앵커** — 오전 강력 압축. 12시 이후엔 1000억+ 라 사실상 pick 막힘

## 7. 최종 결정 (2026-08-11)

외부 AI 리뷰 반영, 아래 파라미터로 배포 확정:

- `LEADER_SEL_MIN_VALUE_EOK = 500` (앵커 값, 기존 400→500)
- `LEADER_SEL_MIN_VALUE_ANCHOR_HHMM = "11:00"` (신규)
- `LEADER_SEL_MAX_VALUE_EOK = 800` (신규, cap)
- `LEADER_SEL_MIN_VALUE_FLOOR_EOK = 150` (신규, 절대 하한)
- `LEADER_SWITCH_UNTIL = "13:00"` (기존, pick_frac 분모)

**최종 공식** (floor/cap 은 시장강도 적용 후, 절대 policy 로):

```python
raw       = anchor_value × (pick_frac(now) / pick_frac(anchor_hhmm))
threshold = clip(raw × market_mult, floor, cap)
# = min(max(raw × mult, 150억), 800억)
```

**최종 시뮬 (500 × 11:00 앵커, floor 150 / cap 800)**

| 시각  | pick_frac | raw | 저조 0.5× | 보통 1.0× | 활황 1.5× |
|-------|-----------|-----|-----------|-----------|-----------|
| 09:30 | 0.125 | 125 | **150** F | **150** F | 188 |
| 10:00 | 0.250 | 250 | **150** F | 250 | 375 |
| 10:30 | 0.375 | 375 | 188 | 375 | 563 |
| **11:00** | 0.500 | 500 | 250 | **500** ⚓ | 750 |
| 11:30 | 0.625 | 625 | 313 | 625 | **800** C |
| 12:00 | 0.750 | 750 | 375 | 750 | **800** C |
| 12:30 | 0.875 | 875 | 438 | **800** C | **800** C |
| 13:00 | 1.000 | 1000 | 500 | **800** C | **800** C |

F=floor 걸림, C=cap 걸림

**결정된 처리 원칙**
1. **앵커** — 11:00 / 500억. 09:30 진입 pool 확보(150억) + 오후 대장주 압축(500→800).
2. **Cap 800억** — 12:30 이후 오후 폭주 방지. pick 이 13:00 종료라도 향후 확장 대비 방어.
3. **pick_frac 은 거래대금 하한에만** — 회전율 · 시장강도 mult 는 session_frac(390분) 유지. avg5 · 하루완결 통계와 정합성 유지.
4. **Floor 150억** — 09:30 저조장 극단 방어. 다만 실측치 튜닝 필요할 수 있음.
5. **선형 근사 주의** — 실제 거래대금은 U자형(초반 30~40% 몰림). 09~10시엔 하한이 다소 너그러움, 12~13시엔 다소 가혹함. 배포 후 로그로 모니터링.

**배포 후 관찰 지표**
- 슬롯당 후보 수 (기존 5~10 → 목표 20~50)
- 거래대금 게이트 통과율
- 통과 종목의 시총/등락률 분포
