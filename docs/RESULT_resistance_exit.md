## 1. 결론 3줄

1. **가설은 절반만 맞았다.** "되밀림"은 실재한다(진입 후 MFE +5% 이상까지 간 거래가 75.5%, 그중 33.0%가 손실로 끝남). 그러나 **원인이 60/120일선 저항은 아니다**: MFE 고점이 찍힌 날 고가가 ma60/ma120 ±2% 안에 있던 비율은 **2.5%** 인데, 같은 거래의 **무작위 보유일 기준선은 12.6%** 다. 즉 최고점은 저항선 근처가 **아니라 오히려 저항선에서 멀리 떨어진 곳**에서 나온다. 애초에 진입 시점에 진입가 위에 저항선이 있는 거래가 전체의 **9.0%** 뿐이다(NEWHIGH·MOMENTUM·GAPGO 는 0.0%).
2. **채택할 저항 규칙(C·C2·C+D·C2+D)은 없다 — 전부 탈락.** OOS 에서 손익비는 1.90 → 2.25 로 오르지만 승률 51.3% → 43.1%, 기대값 +5.74% → +4.09%, 총수익 +44% → +35%, **MDD −14% → −25%, 최악월 −9.3% → −13.8%** 로 안정성 지표가 모두 나빠진다. 7절 판정 기준(MDD 또는 최악월 개선)을 못 넘는다.
3. **유일한 후보는 단순 트레일링 B(trail_after 8% / trail_pct 6%)** 다. OOS 승률 51.3% → **61.9%**, 최악월 −9.3% → **−7.7%**, MDD −14% → −15%(거의 동일), 기대값 +5.74% → +3.13%(플러스 유지), 총수익 **+44% → +35% (−9%p, 상대 −20%)**. 손익비는 1.90 → 1.10 으로 나빠진다. "승률·안정성을 사고 총수익과 손익비를 파는" 교환이며, 지시서 7절 기준은 통과한다. 다만 이는 기존 메모("트레일링은 MDD·월승률만 개선")와 같은 결론이고 새 엣지가 아니다 — **적용은 사용자 승인 사항**.

| PF | 1.82 | 1.51 | −0.31 |
| MDD | −14% | −15% | −1%p (거의 동일) |
| 월승률 | 61% | 63% | +2%p |
| 최악월 | −9.3% | −7.7% | **+1.6%p 개선** |
| 평균 보유 | 26.1일 | 16.2일 | **−9.9일 (짧아짐)** |

- **얻는 것**: 승률 +10.6%p, 보유기간 26일 → 16일, 최악월 −9.3% → −7.7%, 월승률 소폭 개선. "짧게 들고 이기는 비율이 높고 월별로 덜 흔들린다"는 사용자 목표에 정확히 맞는 방향.
- **잃는 것**: 거래당 기대값 45% 감소, 총수익 9%p(상대 20%) 감소, 손익비 1.90 → 1.10. 평균익이 +22.3% → +11.4% 로 반토막 — **크게 가는 종목을 잘라낸다**. 이건 기존 "익절은 해롭다" 결론과 같은 메커니즘이며, 트레일링은 그 손해를 승률·최악월로 되사는 거래다.
- IS 에서도 방향이 같다(승률 53.1%→60.5%, 최악월 −10.6%→−6.3%, 총수익 +19%→+10%). **IS/OOS 부호가 일치**하므로 과최적화는 아니다. 단, 총수익 절반 감소는 IS 에서 더 크다.

## 6. 주의 사항

1. **패널 절단**: 경로 패널은 신호일 D+1 부터 45거래일이다. 30일 타임스톱 안에 대부분 종결되고, 45일 데이터가 끊긴 케이스는 **마지막 종가로 평가청산**(사유 "데이터끝")했고 **모든 규칙에 동일하게** 적용했다. 비중은 A OOS 6%, 트레일 규칙은 3~5%, C 계열 4%. 제외 방식이 아니라 평가청산을 택한 이유는, 규칙마다 조기 청산 빈도가 달라 "제외" 를 쓰면 규칙별 표본이 달라져 비교가 불공정해지기 때문이다. IS 구간은 절단 사례가 0%.
2. **갭 체결**: 손절은 `min(시가, stop_px)` — 전일 대비 갭하락으로 시가가 손절선 아래면 **시가 체결**로 잡았다. 현행 A 도 같은 방식으로 다시 계산했으므로 비교는 공정하다(엔진 `bt_swing/engine.py` 의 기존 동작과도 일치). 진입 당일은 갭 판정을 하지 않는다(진입가가 시가보다 높을 수 있어서).
3. **저항선의 미래 정보 없음**: ma60/ma120 은 `shift(1)` 로 전일까지의 종가만 사용. R 판정에 쓰는 "당일 시가" 는 장 시작에 알 수 있는 값이다. 다만 **막힘 청산가를 당일 종가로** 잡았으므로 실제 운용에선 종가 동시호가 체결 가정이 필요하다(현행 타임스톱과 같은 가정).
4. **데이터 부족 전략**: GAPGO 는 진입 123건(OOS 86건)으로 전략별 수치는 참고용이다. NEWHIGH 397건도 얇다. 두 전략은 저항선이 0% 이므로 C 판정에는 영향이 없다.
5. **총수익 수치의 노이즈**: 슬롯 경쟁 때문에 총수익·MDD 는 랭킹 시드에 민감하다(시드 20개 중앙값 사용). 규칙 간 5%p 이내 차이는 유의하게 보지 않았다. 승률·손익비·기대값은 거래 단위라 시드 무관.
6. **1단계 3항의 선택 효과**: "저항선 터치" 는 주가가 이미 내려간 거래에서만 발생하므로, 막힘 그룹의 낮은 수익률을 저항선의 인과 효과로 읽으면 안 된다. 2단계가 이를 실증한다 — 막힘 청산(29%)을 실제로 집행하면 손실이 확정되면서 MDD 가 오히려 커진다.
7. **적용 시 주의**: B 를 적용한다면 `SWING_TRAIL_AFTER=0.08`, `SWING_TRAIL_PCT=0.06` 계열의 매매경로 변경이며, **사용자 승인 + 파라미터 5곳 동기화**가 필요하다. 이 문서는 검증 결과일 뿐 적용하지 않았다.
